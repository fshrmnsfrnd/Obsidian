| Zeichen | Bedeutung                                                       |
| ------- | --------------------------------------------------------------- |
| `*`     | Wildcard für beliebig **viele** Zeichen                         |
| `?`     | Wildcard für genau **ein** Zeichen                              |
| `[]`    | Wildcard für **bestimmte** Zeichen (z.B. `[abc]`: a, b oder c ) |
## Beispiele
`echo /dev/sd*`
