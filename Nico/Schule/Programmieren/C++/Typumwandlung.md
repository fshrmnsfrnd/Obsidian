# Zahlensysteme

| Zahlensystem | Steuerzeichen |
| ------------ | ------------- |
| Binär        | 0B            |
| Oktal        | 0             |
| Hexadezimal  | 0x            |
`cout << 0B1000` gibt 8 aus.

# Ganzzahl Datentypen
Datentypen von Integern können durch anhängen von Buchstaben an den Wert angegeben werden.

|    |    |
| - | - |
| U oder u | unsigned int |
| L oder l | long int |
| ul | unsigned long int |
| LL | long long int |
| ULL | unsigned long long int |
`cout << 5ul;`
