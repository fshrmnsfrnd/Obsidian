## Syntax
```cpp
if(<Bedingung>){
	//Code
}else if(<Bedingung>){
	//Code
}else{
	//Code
}
```

## Bedingungen
Als Bedingung kann wird klassischerweise ein [[Mathematische Ausdrücke#Vergleich|Vergleich]] verwendet.
Es kann aber auch eine [[Variablen in C++#Wahrheitswerte|Boolsche Variable]] verwendet werden
