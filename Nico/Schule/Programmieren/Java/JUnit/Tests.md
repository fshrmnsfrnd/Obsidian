# Regeln
---
- Eine Funktion macht **eine Sache**
- Tests sollten **nicht** zu **lange** dauern. 
# Arten von Testverfahren
---
## White Box Test
- Wenn den Quellcode kennt
- Sicherstellen dass systematisch getestet wird
## Black Box Test
- Wenn man den Quellcode nicht kennt
- Man findet heraus ob das Programm den Anforderungen entspricht
## Grey Box Test
- Man berücksichtigt die Anforderungen (Wie Black Box)
- Man kennt zumindest die Struktur (Annähernd White Box)
