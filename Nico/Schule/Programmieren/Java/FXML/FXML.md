FXML Projekt erstellen: Maven -> FXML JavaFX Maven Archetype (Gluon)

Um den SceneBuilder zu verwenden: Tools -> Options -> Java -> JavaFX -> Bei SceneBuilder Home den Pfad des SceneBuilder Ordners angeben.

# Projektaufbau
Unter `Source Packages` liegt die `Main` in der Klasse `App`.
Außerdem liegen hier die `Controller Klassen` die für die [[Schule/Programmieren/Java/FXML/Eventhandler|Eventhandler]] Verwendet werden.

Unter `Other Sources` liegen die `.fxml` Dateien. Diese können mit dem SceneBuilder bearbeitet werden
