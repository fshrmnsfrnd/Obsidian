Um eine [[Klassen in Java|Klasse]] zu verwenden muss daraus ein Objekt erzeugt werden
# Objekt erzeugen
---
```java
Klasse objekt = new Klasse();
```

# Attribute
---
`public` Attribute der Klasse können folgendermaßen gelesen und geschrieben werden.

```java
int a = object.b;
object.p = 10;
```
