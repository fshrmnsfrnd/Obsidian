>Durch die [[ANSI-SPARC#3-Schichten Architektur von DBs|3-Schichten-Architektur/ANSI SPARC]] von DBS ergeben sich verschiedene Physische Datenbankarchitekturen.
# Zentralisiertes DBS
---
DBS und Anwendungen auf einem zentralen Computer (Mainframe). User verwenden physische Terminals (Thin clients).
# Das verteilte DBS
---
Ein Netzwerk aus vielen verschiedenen DB Servern.
# Das Client-Server DBS
---
Auf den Clients läuft die Anwendung, das DBS ist auf dem Server.
