# Zutaten
---

| Menge | Zutat       |
| ----- | ----------- |
| 380g  | Mehl        |
| 1 Pck | Trockenhefe |
| 240ml | Wasser      |
| 8g    | Salz        |
| 2 EL  | Olivenöl    |
# Zubereitung
---
1. Alles zusammenmischen und kneten
2. min. 1 Stunde bei Raumtemperatur gehen lassen
3. Danach nochmal durchkneten
4. Dann Ofen auf 230 Grad Ober-/Unterhitze vorheizen
5. Wenn der Ofen heiß ist, den Teig in 3 Stücke teilen und auf dem Blech etwas ausbreiten
6. 5-7 Minuten backen
