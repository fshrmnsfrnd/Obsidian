# Zutaten
---

| Menge | Zutat                |
| ----- | -------------------- |
| 200g  | Zartbitterschokolade |
| 125g  | Butter               |
| 1 Pck | Vanillezucker        |
| 3     | Eier                 |
| 200g  | brauner Zucker       |
| 150g  | Mehl                 |
| 1 TL  | Backpulver           |
| 1 EL  | Kakaopulver          |
# Zubereitung
---
1. Ofen auf Umluft 155 Grad vorheizen
2. Zartbitterschokolade schmelzen
3. Eier, Vanillezucker und braunen Zucker schaumig schlagen. Schokomasse hinzugeben. 
4. Mehl mit Backpulver, einer Priese Salz und Kakaopulver vermengen und mit Eiermasse verrühren. Übrige Schokolade in kleinen Stückchen in den Teig geben. 
5. Den Teil auf das mit Backpapier ausgelegte Blech geben und glattstreichen.
6. Ca. 20 Minuten backen.
