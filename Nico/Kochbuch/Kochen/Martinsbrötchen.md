# Zutaten
---

| Menge   | Zutat            |
| ------- | ---------------- |
| 250g    | Quark            |
| 6 EL    | Milch            |
| 100g    | Zucker           |
| 6 EL    | Öl               |
| 1       | Eier             |
| 400g    | Mehl             |
| 1 Pck.  | Backpulver       |
| 1 Prise | Salz  (optional) |
# Zubereitung
---
1. 1 Blech = ca. 9 Stück
2. Ofen auf 190° Ober-/Unterhitze vorheizen
3. Alles mischen und verkneten
4. Brötchen formen und auf ein Blech legen
5. ca. 15-20 Minuten backen
