# Zutaten
---

| Menge   | Zutat             |
| ------- | ----------------- |
| etwas   | Bolognese         |
| etwas   | Olivenöl          |
| 500g    | Hackfleisch       |
| 1       | Zwiebeln          |
| 2 Zehen | Knoblauch         |
| 1 EL    | Tomatenmark       |
| 800g    | geschälte Tomaten |
| 300g    | Lasagneplatten    |
| etwas   | Reibekäse         |
| 0,5l    | Milch             |
| 30g     | Butter            |
| 40g     | Mehl              |
| etwas   | Salz              |
| etwas   | Pfeffer           |
| etwas   | Zitronensaft      |
# Zubereitung
---

1. Ofen auf 180C Umluft vorheizen
2. ## Ragú Bolognese
3. Olivenöl erhitzen, das Hackfleisch darin anbraten und die Zwiebeln dazugeben. 
4. Knoblauch in feinen Scheiben und Tomatenmark dazu rühren und mit braten. 
5. Mit den Dosentomaten aufgießen, salzen und pfeffern. 
6. Rotwein nach Belieben beifügen. 
7. Das Ragú mindestens eine halbe Stunde lang bei geöffnetem Topf einkochen lassen.
8. ## Béchamelsauce
9. Butter in einem kleinen Topf schmelzen und das Mehl mit dem Schneebesen unterrühren anschwitzen. 
10. Die Milch dazu gießen und die Sauce glatt rühren. 
11. Genug rühren, dass keine Klümpchen entstehen. 
12. Die Sauce sollte fast eine halbe Stunde lang auf kleiner Flamme köcheln, damit sie den Mehlgeschmack verliert. 
13. Mit Salz, Pfeffer und Zitronensaft abschmecken.
14. ## Lasagne
15. In einer gebutterten Form etwas Ragú Bolognese verteilen, eine Schicht Lasagneplatten darauf legen, die Nudelschicht wieder mit Ragú und dann mit einer Schicht Béchamel bedecken. 
16. Anschließend wieder eine Schicht Nudeln, Ragú und Béchamel.
17. So Schicht für Schicht die Form füllen. 
18. Die letzte Schicht sollte die Béchamelsauce bilden. 
19. Dick mit geriebenem Käse bestreuen.
20. Die Lasagne im heißen Backofen bei 180 °C Umluft ca. 30 - 40 Minuten backen, bis die Kruste goldbraun ist.
