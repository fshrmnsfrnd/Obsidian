# Zutaten
---

| Menge      | Zutat          |
| ---------- | -------------- |
| 4          | Eier           |
| 400 g      | Mehl           |
| 300 ml     | Milch          |
| 180g       | Zucker         |
| 80 ml      | Öl  (optional) |
| 1 Pck(8g)  | Vanillezucker  |
| 1 Pck(16g) | Backpulver     |
| 1 Prise    | Salz           |

# Zubereitung
---
1. Waffeleisen vorheizen
2. Alles zusammenschmeißen, rühren und immer eine halbe Schöpfkelle ins Waffeleisen. Herausnehmen bevor die Waffel braun ist.
