# Zutaten
---

| Menge   | Zutat             |
| ------- | ----------------- |
| 2 Zehen | Knoblauch         |
| 200g    | Sahne             |
| 500g    | passierte Tomaten |
| 200g    | Gouda             |
| 500g    | Nudeln            |
| 200g    | Mozarella         |
# Zubereitung
---
1. Ofen auf 180° Ober/Unterhitze vorheizen
2. Gnocchi / Nudeln nach Packung kochen.
3. Knoblauch schneiden.
4. In einer Pfanne mit Öl den Knoblauch kurz anbraten, dann die Sahne und die Tomaten dazugeben. Gouda unterrühren und würzen. Kurz aufkochen. 
5. Alles in eine Auflaufform geben, und mit Mozzarella bestreuen
6. ca. 15 Minuten in den Ofen geben.
