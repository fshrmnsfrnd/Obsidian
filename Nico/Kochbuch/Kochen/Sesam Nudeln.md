# Zutaten
---

| Menge   | Zutat                        |
| ------- | ---------------------------- |
| 250g    | Reisbandnudeln               |
| etwas   | Sojasauce                    |
| etwas   | Hoi Sin Sauce                |
| etwas   | Sriracha Sauce               |
| etwas   | Sesamöl geröstet             |
| etwas   | Sesamkörner weiß             |
| 1       | Avocado                      |
| etwas   | Erdnüsse gesalzen (optional) |
| 2 Zehen | Knoblauch                    |
| 2       | Frühlingszwiebeln            |
| etwas   | Öl                           |
# Zubereitung
---
1. Nudeln nach Packung kochen
2. Knofi und Frühlingszwiebel schneiden und in eine Schüssel 
3. Sesam dazugeben
4. Soßen dazugeben
5. Öl erhitzen
6. Zutaten mit heißem Öl übergießen. 
7. Avocado schneiden und Erdnüsse zerhacken. 
8. Alles über die Nudeln geben
