# Zutaten
---

| Menge | Zutat               |
| ----- | ------------------- |
| 700g  | Tortellini          |
| etwas | Parmesan (optional) |
| 50g   | Butter              |
| 80g   | Mehl                |
| 600g  | Milch               |
| 1     | Zwiebeln            |
| 1Pck  | Speckwürfel         |
# Zubereitung
---
1. Tortellini kochen nach Packungsangabe
2. Butter im Topf schmelzen
3. Zwiebeln dazu
4. Mehl dazugeben und erhitzen
5. Milch, Schinkenwürfel und Salz dazugeben
6. Kurz aufkochen
7. Alles zusammenkippen
