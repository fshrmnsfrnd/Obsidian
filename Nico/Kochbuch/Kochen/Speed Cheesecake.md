# Zutaten
---

| Menge | Zutat               |
| ----- | ------------------- |
| 5     | Biscoff Kekse       |
| 200g  | Griechischer Jogurt |
| etwas | Obst                |
| 1EL   | Brauner Zucker      |
# Zubereitung
---
1. Die Kekse auf den Boden einer Schüssel legen, sodass der Boden einigermaßen bedeckt ist.
2. Mit griechischem Jogurt bedecken
3. Eine Schicht Obst(z.B. Mandarinen) (WICHTIG: Keine Kiwi oder Ananas)
4. So viele schichten bis die Schüssel voll ist
5. Zum Abschluss oben eine Schicht Keksbrösel und braunen Zucker
6. Über Nacht in den Kühlschrank
