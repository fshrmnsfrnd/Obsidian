# Zutaten
---

| Menge   | Zutat                    |
| ------- | ------------------------ |
| 2       | Eier                     |
| 200ml   | Milch                    |
| 1 Prise | Salz (optional)          |
| 1 Prise | Zucker (optional)        |
| 200g    | Mehl                     |
| 60ml    | Mineralwasser (optional) |
# Zubereitung
---
1. Pfanne erhitzen
2. Eier mit Milch, Zucker, Salz, Mehl und Mineralwasser zu einem glatten Teig rühren. 
3. Bei Bedarf noch etwas Mehl oder Wasser hinzugeben, um die gewünschte Konsistenz zu erreichen.
4. Eine beschichtete Pfanne mit etwas Speiseöl erhitzen. 
5. Mit einer Schöpfkelle eine Kelle Teig in die Pfanne geben und die Pfanne kurz in jede Richtung schwenken um den Teig zu verteilen. 
6. Den Pfannkuchen von beiden Seiten etwa 1-2 Minuten bräunlich ausbacken. 
7. Warm genießen.
