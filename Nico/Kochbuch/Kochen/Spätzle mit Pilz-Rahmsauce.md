# Zutaten
---

| Menge   | Zutat        |
| ------- | ------------ |
| 1       | Zwiebeln     |
| 2 Zehen | Knoblauch    |
| 1 EL    | Butter       |
| 400g    | Champingnons |
| 200g    | Sahne        |
| 1EL     | Mehl         |
| 200ml   | Wasser       |
| 500g    | Spätzle      |
| 2Pck    | Bratensauce  |
# Zubereitung
---
1. Die kleingehackte Zwiebel mit Knoblauch kurz andünsten.
2. Dann geviertelte oder in Scheiben geschnittene Champignons zufügen und ca. 4 bis 5 min braten.
3. Nun die fertigen Spätzle zufügen und ebenfalls kurz braten. Nun Pfeffer, Salz, Paprika edelsüß und etwas Chili zugeben.
4. Mehl, Wasser und die Bratensauce in einen Topf geben, und nach Anleitung der Bratensauce zubereiten
5. Die Spätzle so lange braten bis sie gut braun sind
