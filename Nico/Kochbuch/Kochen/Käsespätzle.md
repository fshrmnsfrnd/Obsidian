# Zutaten
---

| Menge | Zutat      |
| ----- | ---------- |
| etwas | Zwiebeln   |
| etwas | Butter     |
| 400ml | Sahne      |
| etwas | Salz       |
| etwas | Pfeffer    |
| 200g  | Emmentaler |
| 1kg   | Spätzle    |
# Zubereitung
---
1. Zwiebeln in Butter anbraten, mit Sahne ablöschen und mit Salz und Pfeffer abschmecken. 
2. Kurz aufkochen, dann die Hälfte vom Käse dazugeben und gut durchrühren.
3. Die Spätzle unterheben.
4. Die Mischung in eine gefettete Auflaufform geben und mit dem restlichen Käse bestreuen
5. Im heißen Backofen bei 200 °C Ober-/Unterhitze ca. 20 Minuten überbacken, bis die gewünschte Bräune erreicht ist.
