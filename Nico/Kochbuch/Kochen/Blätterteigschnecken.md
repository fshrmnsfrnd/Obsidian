# Zutaten
---

| Menge | Zutat          |
| ----- | -------------- |
| 1     | Blätterteig    |
| 1 Pck | Creme Fresh    |
| 250g  | Mozarella      |
| 250g  | Schinkenwürfel |
# Zubereitung
---
1. Ofen auf 200 Grad Umluft vorheizen
2. Alles auf den Teig, zusammenrollen, schneiden.
3. Ca. 20 Minuten backen
