# Zutaten
---

| Menge | Zutat            |
| ----- | ---------------- |
| 250g  | weiche Butter    |
| 100g  | Zucker           |
| 150g  | Brauner Zucker   |
| 1TL   | Vanilleextrakt   |
| 2     | Eier             |
| 360g  | Mehl             |
| 1TL   | Backpulver       |
| 200g  | Chocolate Chunks |
# Zubereitung
---
1. Ofen auf 160 Grad Umluft vorheizen
2. Alles zusammen mixen, Kleckse auf die beiden Bleche und 10 bis 12 Minuten backen
