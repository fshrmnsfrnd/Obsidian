# Zutaten
---

| Menge   | Zutat         |
| ------- | ------------- |
| 250g    | Butter        |
| 200g    | Zucker        |
| 1 Pck   | Vanillezucker |
| 1 Prise | Salz          |
| 5       | Eier          |
| 250g    | Mehl          |
| 3TL     | Backpulver    |
| 2EL     | Backkakao     |
| 1EL     | Zucker        |
| 50ml    | Milch         |
# Zubereitung
---
1. Ofen auf 160 Grad Umluft vorheizen
2. Butter, Zucker, Vanillezucker, Eier und Salz schaumig schlagen. 
3. Mehl mit Backpulver mischen und zusammen mit 3EL Milch unterrühren.
4. Hälfte in die eingefettete Backform füllen.
5. Den Rest mit Kakao, Zucker und Milch verrühren, und ebenfalls in die Form füllen. Mit einer Gabel etwas vermischen.
6. Ca. 50 Minuten Backen
