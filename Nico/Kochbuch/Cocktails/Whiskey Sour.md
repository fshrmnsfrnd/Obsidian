>Wenn das Leben dir Zitronen gibt, machen einen Whiskey Sour draus 
# Zutaten
---

| Menge      | Zutat        |
| ---------- | ------------ |
| 4.5 cl     | Whiskey      |
| 3 cl       | Zitronensaft |
| 1,5 cl     | Zuckersirup  |
| 1 frisches | Eiweiß       |
# Zubereitung
---
1. Alles mit Eis in den Shaker und shaken
2. Auf frischem Eis servieren
