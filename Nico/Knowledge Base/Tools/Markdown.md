# Blockquotes
---
```markdown
> This is
> a blockquote
>
> > Nested
> > Blockquote
```
**Sample:**
> This is a blockquote

# Unordered List
---
```markdown
* Item 1
* Item 2
    * item 3a
    * item 3b
```
or
```markdown
- Item 1
- Item 2
```
or
```markdown
+ Item 1
+ Item 2
```
# Checkbox
---
```markdown
- [ ] Checkbox off
- [x] Checkbox on
```
# Ordered List
---
```markdown
1. Item 1
2. Item 2
    a. item 3a
    b. item 3b

```
