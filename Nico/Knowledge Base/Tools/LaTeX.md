TeX ist ein schon lange bestehendes Textsatzsystem und zugleich eine Sprache, in der man LayoutAnweisungen in Form von Makros in den Text einfügt. Das Ausgabeformat ist meistens ein gedrucktes Dokument oder eine PDF-Datei. Inhalt und Layout werden möglichst getrennt. Heute schreibt kaum mehr jemand reine TeX-Dokumente. Es existieren Programmpakete, die die Benutzung von TeX einfacher machen, unter anderem LaTeX. Die verschiedenen Frameworks unterscheiden sich in Details. Wir verenden LuaLaTeX. Zum Erstellen von Dokumenten brauchen sie eine TeX-Distribution, zum Beispiel Tex Live für Unixartige Betriebssysteme und Windows. Ein Texteditor, der TeX unterstützt, erleichtert die Arbeit. Einer von vielen ist TeXworks.
