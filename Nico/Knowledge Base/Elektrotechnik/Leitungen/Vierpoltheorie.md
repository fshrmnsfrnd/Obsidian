- Je länger eine Leitung, desto mehr fallen die Eigenschaften der Komponenten R, L, C und G ins Gewicht.
- Bezogen auf eine bestimmte Länge, werden die entsprechenden Werte in Datenblättern als Leitungsbeläge angegeben
- Abhängig von den Leitungsbelägen ist auch der Dämpfungsbelag.

R: Leitungswiderstand
R' : Widerstandsbelag $\frac{\ohm}{100m}$ 
C: Kapazität durch Hin- und Rückleiter (el. Feld zwischen unterschiedlichen Potentialen)
C' : Kapazitätsbelag $\frac{nF}{100m}$ F = Farad
L: Induktivität einer Leitung (magnetisches Feld eine stromdurchflossenen Leitung)
L' : Induktivitätsbelag $\frac{\micro H}{100}$ `[L]` = H = Henry
G : Kehrwert des Isolationswiderstands
G' : Ableitungsbelag $\frac{\micro S}{100m}$ (Mikro Siemens)
