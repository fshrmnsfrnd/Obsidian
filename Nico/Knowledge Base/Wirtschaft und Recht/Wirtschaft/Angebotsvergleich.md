# Quantitativer Angebotsvergleich
---
Ein Quantitativer Angebotsvergleich bezieht sich immer auf den Stückpreis.

Listeneinkaufspreis (netto)  
- Lieferantenkosten  
---------------------------------------  
= Zieleinkaufspreis  
- Lieferantenskonto  
---------------------------------------  
= Bezugskaufpreis  
+ Bezugskosten (z. B. Fracht, Lieferkosten, mögl. Zölle usw.)  
---------------------------------------  
= Bezugspreis

# Qualitativer Angebotsvergleich
---
z. B. Zielbedingungen, Qualität, Service, Erfahrungen etc.

1. Kriterien bestimmen
2. Gewichtung der Kriterien (insg. 100%)
3. Punkte (Noten) zuordnen
4. Multiplikation Punkte x Gewicht
5. Ermittlung des besten Anbieters (durch Addition)
