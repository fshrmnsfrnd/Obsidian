>Eine Signatur ist ein digitales Verfahren, um die Integrität von Daten zu gewährleisten und die Urheberschaft zu prüfen.

![[Pasted image 20251111150125.png]]

- Sender rechnet mithilfe eines geheimen Signaturschlüssel (Private Key) zu einer Nachricht einen Wert aus. Dieser kann von einem öffentlichen Schlüssel verifiziert werden
- Urheberschaft wird durch [[Zertifikate]] bescheinigt
