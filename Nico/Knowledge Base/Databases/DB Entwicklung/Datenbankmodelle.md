# Andere Datenbankmodelle
- RDF Store
	- Unterklasse von Graph DBMS
	- Informationen werden als Subjekt-Prädikat-Objekt gespeichert (Tripel)
- Spatial DBMS
	- räumliches DBMS
	- für Geodaten oder Raum- Zeitberechnung
- Vector DBMS

	- [[MongoDB]]
	- [[Redis|Redis]]
	- Neo4j
### Datenmodelle
- Document Store
	- NoSQL
	- Keine einheitliche Struktur
	- Kann unterschiedlich viele Spalten pro Zeile haben
- Key-Value-Stores
	- Speichert nur Paare von Schlüsseln und Werten
	- Sehr Performant
- Graph DBMS
	- Wie Obsidian Graph (semantisches Netz) 
	- z.B. Userauswertungen gut möglich
