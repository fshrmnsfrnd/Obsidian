# Demultiplexer

"Drehbarer Schalter" (Analogtechnik)
![[Pasted image 20250508101925.png]]

**Digital:** Ausgangsignal $Q_i$​ wird durch ein Steuersignal $S$ ausgewählt.  
Wenn $S$ eine Wortbreite von $n$ Bit, können höchstens 2n2n Ausgänge geschalten werden.
