>Sind eine weitere Kategorie von [[Views#View Groups|ViewGroups]] .
>Ein Layout Manager haben die einzige Aufgabe die Positionierung der enthaltenen [[Views|Views]] zu steuern

# Arten von Layout Managern
---
## Constraint Layout
- Wird empfohlen
- Flexibel
## Linear Layout 
- horizontal oder vertikal anordnen
- Platzbedarf kann über `Gravity` eingestellt werden
## Frame Layout
- Hier kann ein Bildschirmbereich für einen View festgelegt werden
## Table Layout
- Zeilen werden durch `TableRow` Objekte gebildet
## Grid Layout (Legacy)
- Grid Layout
## Relative Layout (Legacy)
- Relative Anordnung zum Bildschirm und anderen Objekten
