# Log Methoden

| Methode                   | Beschreibung       |
| ------------------------- | ------------------ |
| `Log.a(<tag>, <message>)` | Assert Ereignisse  |
| `Log.d(<tag>, <message>)` | Debug Ereignisse   |
| `Log.e(<tag>, <message>)` | Error Ereignisse   |
| `Log.i(<tag>, <message>)` | Informationen      |
| `Log.v(<tag>, <message>)` | Verbose Ereignisse |
| `Log.w(<tag>, <message>)` | Warnungen          |
