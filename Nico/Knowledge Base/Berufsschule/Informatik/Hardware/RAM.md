Es gibt unterschiedliche Arten von Speichern. In Speichern werden Informationen für eine bestimmte Zeit gespeichert. Eine Art von Speicher ist z. B. Cache (in CPUs), er Speicher zwischen Ergebnisse der [[CPU]]. Es gibt aber auch noch so genanntes **RAM** (**R**andom **A**ccess **M**emory). Das Random steht für wahlfrei. Der Arbeitsspeicher (RAM) ist wie der Cache auch ein Flüchtiger Speicher (Strom weg -> Daten weg). Dem gegenüber ist die Festplatte als nicht flüchtiger Speicher.  Der RAM ist also so zu sagen das Kurzzeitgedächtnis. Hier können Programme oder Zwischenergebnisse abgelegt werden, und schnell wieder abgerufen werden.

# Beispiele flüchtig und nicht flüchtiger Speicher:
---

| **flüchtig** | **nicht flüchtig**        |
| ------------ | ------------------------- |
| RAM          | SSD                       |
| Cache        | HDD                       |
| CMOS         | USB-Stick / Flashspeicher |
| VRAM         | EEPROM                    |
# Kenngrößen und Fachbegriffe:
---

|**Größe**|**Definition**|
|---|---|
|X GB (2x Y GB)|X GB an Speichergröße in Form von 2x Y GB|
|DDRX|Version X des RAM-Riegels (Double Data Rate)|
|X MHz|Taktrate in MHz|
|PC 4 24000|DDR4 mit 8 Bit Bus Breite|
|CL X|X Takt Latency (Verzögerung von Senden bis Ankunft)|
|ECC|**E**rror **C**orrection **C**ode (Automatische Korrektur von Fehlern)|
|DIMM|Dual Inline Memory Module (Kontakte auf beiden Seiten 2x 32 Bit = 64 Bit)|
|UDIMM|**U**nbuffered Dual Inline Memory Module (Speichert nichts auf dem Cache, Privatkunde)|
|RDIMM|**R**egistered Dual Inline Memory Module (übernimmt die Registrierung (hat 8 Bit mehr); Weniger Energy; Server)|
|SO-DIMM|**S**mall **O**utline Unbuffered **D**ual **I**nline **M**emory **M**odule (Laptop-RAM)|
|tRCD|**R**ow Address to **C**olumm Address **D**elay (Zeitdauer zwischen der Aktivierung einer Zeile / Bank und der  <br>Absendung eines Lese- oder Schreibkommandos)|
|tRP|**R**ow **P**recharge Time (Zeitdauer zwischen der Deaktivierung einer Zeile / einer Bank und der erneuten Aktivierung  <br>einer Zeile in der selben Bank)|
|tRAS|**R**ow **A**ctive Time (Zeit, die nach der Aktivierung einer Zeile verstrichen sein muss, bevor ein Kommando zum  <br>Deaktivieren der Ziele gesendet werden darf)|
