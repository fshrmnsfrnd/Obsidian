Man setzt die Gleichung der Geraden in die Gleichung der Ebene ein. An der Lösung der Parameterwerte kann die Lagebeziehung ablesen

|                                  |                                       |
| -------------------------------- | ------------------------------------- |
| Genau ein Lösung                 | g und E schneiden sich in einem Punkt |
| Keine Lösung                     | Echt parallel                         |
| Unendlich viele Lösungen (0 = 0) | g liegt in E                          |
Eine Gerade ist senkrecht zu einer Ebene wenn ihr Ortsvektor $\gamma$  ein vielfaches des Normalenvektors der Ebene ist
