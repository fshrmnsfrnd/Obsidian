>Spurpunkte sind die Durchstoßpunkte einer Geraden mit den Koordinatenebenen

# Welche Ebene wird durchstoßen?
---

| Fall                              | Folgerung |
| --------------------------------- | --------- |
| $g$ durchstößt die $x_1x_2$-Ebene | $x_3=0$   |
| $g$ durchstößt die $x_1x_3$-Ebene | $x_2=0$   |
| $g$ durchstößt die $x_2x_3$-Ebene | $x_1=0$   |
# Lösungsfälle
---

| Zahl der Spurpunkte | Erklärung                              |
| ------------------- | -------------------------------------- |
| 3                   | Schneidet alle Ebenen                  |
| 2                   | Ist zu einer Ebene (2 Achsen) parallel |
| 1                   | Ist zu einer Achse parallel            |
| 0                   | unmöglich da unendlich lang            |
# Spurpunkte berechnen
---
**Beispiel**
Spurpunkt $x_1x_2$ Ebene berechnen:
1. $x_3 = 0$ setzen
2. In 0 in $|||$ einsetzen (Bsp.: $0 = 2 + \gamma \ 2$)
3. $\gamma$ bestimmen (hier $\gamma = -1$)
4. $\gamma$ in Geradengleichung einsetzen
5. Was rauskommt ist der Schnittpunkt mit der $x_1x_2$ Ebene
